## Findings

1. **Why v1 showed MLP 0.366 vs NDWI-only 0.00056 at Cape Canaveral.** Sentinel-2 L2A scenes with processing baseline ≥ 04.00 (all current scenes; these are 05.13) store `DN = reflectance × 10000 + 1000`. v1 divided by 10000 without removing the +1000 offset, which pushes every normalized-difference index toward 0: dark water that truly has NDWI ≈ 0.5 read below 0.15. So NDWI>0.15 found almost no water (IoU 0.03 vs reference at Cape Canaveral). The v1 MLP hid this because its weak labels were percentile-based (top-decile NDWI is always "water"), so it adapted to the compressed scale. At Cape Canaveral, where the reference says ~45% of clear pixels are permanent water, it happened to be close (IoU 0.93).
2. **The v1 MLP is not trustworthy.** The same percentile rule labels the brightest 10% of *any* scene as water. In the dry Phoenix control it called 33% of clear pixels water (precision 0.001). Over the Lake Poinsett floodplain it found none (IoU 0.0).
3. **With the offset fixed, simple indices match the reference well.** MNDWI>0 on SCL-clear pixels has the best overall agreement: IoU 0.91 at the lagoon, 0.82 on the floodplain, 0.997 on the lake, and IoU 0.47 / recall 0.53 on the narrow Mississippi channel, the best of the offset-corrected methods there (limited by the ~100 m grid; v1 MLP scored IoU 0.51 there but is unusable elsewhere). Its worst false-water rate outside reference water was 0.93% of pixels, in the Phoenix urban control.
4. **v2 MLP** (absolute weak labels, negatives include urban/soil) agrees with the reference where it trains (IoU 0.92 / 0.84 / 0.996). It correctly refuses to train when there are too few confident water pixels (Mississippi, Phoenix), so it can't be the primary mask.

## Method chosen

- **Primary water mask: MNDWI > 0 on SCL-clear pixels**, with the BOA offset applied. It had the best mean IoU across the water AOIs and works without training.
- **v2 MLP is a cross-check only.** Its IoU with the primary feeds confidence. It never overrides the primary.
- **Flood delta = new water outside reference permanent water** (JRC occurrence ≥ 50% OR WorldCover 2021 class 80), recent minus baseline.
- **Noise floor = 1% of clear pixels**, rounded up from the largest false-water rate measured (0.93%, Phoenix). Smaller changes are reported as not significant.
- **Confidence:** reference recall below 0.7 or method IoU below 0.6 lowers confidence (see `pipeline/terragent_eo/confidence.py`).
