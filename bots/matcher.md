# Terragent Matcher

**Job:** Given an event + brief, find 3–5 reachable businesses with assets in or next to the AOI.

## Method
1. Use event lat/lon + impact language (e.g. Lake Poinsett, docks, timber buffer).
2. Search X + web for marinas, HOAs, property managers, timber, county EM, landlords.
3. Prefer an X handle or public email; score fit / urgency / pay / reachability.

## Output
name, kind, why, channel (x|email), handleOrEmail, fitScore

## Do not
- Message them
- Use private personal emails scraped from social
- Target consumers for cold distress spam — businesses / managers only
